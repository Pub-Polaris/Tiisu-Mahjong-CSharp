# 界面设计交接模板（DESIGN_SPEC）

> 给北极星：你按这份模板给设计，我按设计填 `Assets/layout/*.json`，**不用改渲染代码**。
> 当前实现：WinForms 一个铺满的 `ScreenHost`（SkiaSharp 自绘），逻辑坐标固定 **1280×720**，等比缩放居中。

## 1. 画布

| 项 | 值 |
|---|---|
| 逻辑尺寸 | 1280 × 720（按此出设计稿最省事） |
| 缩放 | 等比 letterbox，黑边 |
| 最小窗口 | 960 × 540 |
| 高 DPI | 自动（设计稿按逻辑像素标注即可） |

## 2. 屏幕清单

| id | 说明 | 当前状态 |
|---|---|---|
| `table` | 牌桌（手牌/牌河/副露/计分/中心信息） | 骨架已有（程序化绘制 + 真实牌面） |
| `menu` | 主菜单 | 骨架已有（JSON 布局） |
| `result` | 结算 | 未做 |
| `intro` | 片头/过场 | 未做（建议用 `<video>` 思路 → Skia 播帧序列） |

## 3. 元素描述格式（`Assets/layout/<screen>.json`）

```json
{
  "width": 1280, "height": 720,
  "elements": [
    { "id": "btnStart", "type": "button",
      "x": 500, "y": 460, "w": 280, "h": 64, "radius": 14,
      "text": "开始对局", "action": "start", "fontSize": 24,
      "fill": "#223438", "border": "#c4a860", "fontColor": "#f0ecdc" }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `type` | `rect` / `text` / `tile` / `button` / `image`（image 预留） |
| `x,y,w,h` | 逻辑坐标矩形（左上原点） |
| `tileId` | 牌面：`1m`…`9m`、`1p`…、`1s`…、`1z`东 … `7z`中 |
| `action` | 点击时触发的动作码（`mode:N` / `settings` / `quit` / 自定义；`resume` 已随「继续上局」停用，不再有入口） |
| `fill` / `border` / `fontColor` | `#RRGGBB` 或 `#RRGGBBAA` |
| `radius` | 圆角；0 = 直角 |
| `fontSize` | 字号（像素） |

## 4. 交互状态（我会按此实现）

| 状态 | 需要的视觉差异 |
|---|---|
| normal | 默认 |
| hover | 边框变亮 / 底色变化 / 上浮 2px（选一种，写清楚） |
| pressed | 下沉 1px + 底色变暗 |
| disabled | 降低透明度到 40%，无 hover |
| selected | 高亮描边（如手牌抬起 14px + 金色光晕，现在就是这样） |

## 5. 需要你提供的资源

| 资源 | 形式 | 说明 |
|---|---|---|
| 牌面 | 已有（`mj_tiles/*.svg`，34 张） | 若换皮，替换 SVG 后跑 `python scripts/export_tiles.py` 重新栅格化 |
| 牌背 / 侧面 | 需要 | 现在是我用程序画的绿色块 |
| 人物立绘 | PNG/WebP（透明底） | 名字建议 `role_<id>.png` |
| 背景 | PNG（1280×720 或更大） | 每屏一张 |
| 动效帧 | 序列帧 PNG（透明底） | 告诉我帧数/尺寸/循环方式 |

## 6. 动画与转场（可选）

- 屏切换：当前是 150ms 黑场淡入；可改成滑动/缩放，告诉我曲线与时长。
- 牌动画（摸/打/碰）：现在只有「旋转牌」示意；需要你给出：位移轨迹、时长、缓动。
- 立直/和牌特效：需要帧序列或参数化描述。

## 7. 落地流程

1. 你给：设计稿（图片或标注图）+ 上面第 4/5/6 节的参数
2. 我改：`Assets/layout/*.json` + 新增资源文件 + 必要时给 `Screen` 子类加少量逻辑
3. 验收：`dotnet run` 看效果；`--render out.png 0.6 menu` 可离屏出图给我自己比对

> 原则：**版式走数据，逻辑走代码**。同一屏的坐标改动不应该碰 `.cs`。
