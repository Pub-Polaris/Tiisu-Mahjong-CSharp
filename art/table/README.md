# 牌桌皮肤（skin.json + PNG/图集）

美工只交「图 + 清单」，不动代码：牌位、命中区、规则、文字排版全部由布局和渲染代码决定，
皮肤只替换静态视觉。**没有皮肤时视觉与旧版逐像素一致**（已用 1400×1400 出图做像素比对）。

## 目录

| 路径 | 作用 |
| --- | --- |
| `src/Tiisu.App/Assets/ui/skin.json` | 随包启用的皮肤清单（放这里构建后自动进 exe 旁 `Assets/ui/`） |
| `src/Tiisu.App/Assets/ui/skin.example.json` | 带注释的清单样例，不参与加载 |
| `art/table/skin-demo/` | 示例皮：`skin.json` + `skin-atlas.png` + 生成脚本 |
| `artifacts/skin-preview/` | 出图与性能对照 |

## 清单格式

```json
{
  "version": 1,
  "name": "青苔木台",
  "author": "美术署名",
  "scale": 2,
  "atlas": "skin-atlas.png",
  "background": "#0d1512",
  "regions": {
    "table":        { "src": [0, 0, 512, 512],      "slice": [96, 96, 96, 96] },
    "center-plate": { "src": [520, 0, 320, 200],    "slice": [40, 40, 40, 40] },
    "river-bed":    { "src": [520, 208, 240, 160],  "slice": [32, 32, 32, 32] },
    "button":       { "src": [520, 376, 160, 64],   "slice": [20, 20, 20, 20] },
    "shadow":       { "src": [520, 448, 256, 256],  "slice": [80, 80, 80, 80], "inflate": 40 },
    "frame":        { "src": [0, 520, 320, 320],    "slice": [88, 88, 88, 88] }
  }
}
```

| 字段 | 含义 |
| --- | --- |
| `version` | 清单版本，当前 `1`；高于运行时的版本整张皮忽略（回退程序化） |
| `scale` | 源像素 ÷ 逻辑像素，`2` = 2× 交付图；单区域可用 `scale` 覆盖 |
| `atlas` / `image` | 图集文件名（相对清单目录，或绝对路径） |
| `background` | 桌面外圈底色 `#RRGGBB` / `#AARRGGBB`，缺省沿用 `#141e18` |
| `regions` | 具名区域，键见下表；未知区域忽略（向前兼容） |

单个区域：

| 字段 | 含义 |
| --- | --- |
| `image` | 该区域单独一张图（覆盖 `atlas`） |
| `src` / `rect` | 图集切片 `[x, y, w, h]`（**源像素**）；缺省 = 整图 |
| `slice` | 九宫格边距 `[左, 上, 右, 下]`（**源像素**）；缺省 = 整图拉伸 |
| `scale` | 源像素 / 逻辑像素 |
| `alpha` | 0–1 |
| `inflate` | 目标矩形外扩（负值内缩），逻辑像素 |

## 具名区域

| 键 | 画在哪 | 目标尺寸（1400 画布） | 建议九宫格角块 |
| --- | --- | --- | --- |
| `table` | 桌面主体（margin 16 内缩） | 1368×1368 | 40–64 逻辑（示例 48） |
| `center-plate` | 中央信息板底板（文字仍由代码逐帧画） | 400×400 | 16–24 逻辑（示例 20） |
| `river-bed` | 四家牌河底垫布 | 368×352 / 352×368 | 12–20 逻辑（示例 16） |
| `button` | 牌桌内小面板：报听标 66×24、AI 档位标 82×24、风位方块 38×38 复用 | 按上面尺寸缩放 | ≤10 逻辑（示例 10） |
| `frame` | 整张画布压边 | 1400×1400 | 30–48 逻辑（示例 44） |
| `shadow` | 桌面下方投影（画在桌面底下） | 桌面外扩 `inflate` | 与 `inflate` 相同的逻辑边宽（示例 40） |

牌面（`tiles.png`）不是皮肤的一部分：牌面由牌局数据逐张绘制，换皮肤不影响牌面。

## 规则与坑

- **缺什么回退什么**：某区域没配、图缺失、JSON 写错 → 该区域继续走代码里的程序化绘制；
  整张清单坏了只是没有皮肤，牌桌照常开。加载失败会在 stderr / 调试输出留一行 `[skin] …`。
- **每帧不解码图**：图片进程内解码一次，之后只做采样缩放。单张图别超过 2048×2048（没有收益）。
- **不要用半透明九宫格拼大面板**：九个格子分开画，边界可能有 1px 接缝；大块面板用实色或整图。
  （`shadow` 是唯一的例外——它本来就是渐变透明，且只出现在桌面边缘。）
- 九宫格拉伸时**四角保持逻辑原始尺寸**，别把角块画得太小（小于 24 逻辑会糊）。
- 静态层按设备缩放预合成：拖动窗口改变大小时会重建一次，正常游玩（窗口不动）不重建。

## 怎么预览 / 怎么启用

```powershell
# 1) 临时用这个皮出图（不装进包里）
$env:TIISU_SKIN = "$PWD\art\table\skin-demo"
tools\Tiisu.DevTools\bin\Debug\net10.0-windows10.0.19041\Tiisu.DevTools.exe `
  --render-table-png artifacts/skin-preview/table-skin.png --variant flat

# 2) 随包启用：把 skin.json + 图放进 src/Tiisu.App/Assets/ui/ 再构建
# 3) 强制关皮肤（对照用）、强制关静态层缓存（排障用）
$env:TIISU_SKIN = "off"
$env:TIISU_STATIC_LAYER = "off"
```

## 性能（同一台机器，1400×1400 CPU 光栅，--bench 600，`avg / p95`）

| 场景 | 帧耗时 | 说明 |
| --- | --- | --- |
| 无皮肤（默认程序化） | 4.02–4.07 / 4.26–4.36 ms | 与改动前一致（出图逐字节相同） |
| 皮肤 + 静态层缓存 | 4.35–4.37 / 4.62–4.64 ms | 皮肤模式默认走这里（比默认多约 0.3ms） |
| 皮肤、缓存关闭 | 17.55–17.63 / 17.98–18.18 ms | 对照用：静态层每帧重画 |

静态层缓存把皮肤模式的静态层（桌面/中央板/牌河底/边框/阴影）压成**一次 1:1 位块拷贝**，
文字、手牌、牌河、按钮状态仍然每帧实时绘制；预合成在设备像素网格上做，窗口缩放/DPI 变化只会
重建一次，像素相位与直接绘制完全一致。

## 自检

```powershell
dotnet run --project art/table/skin-demo/verify -c Debug
```

覆盖「没皮肤即回退、六个区域、静态层只该建的时候建、缺区域回退、坏清单容错」。
退出码 0 = 全过。
