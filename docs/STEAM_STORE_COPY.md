## 中文

**简短描述**

七子麻将：单机日麻规则变体，7 赋起和、报听、错和、场供与四档 AI。

**长描述**

《七子麻将》是七子规则的单机桌面实现：136 张牌、7 赋起和、报听锁手、错和罚、场供池与四人 AI 对局。

- 完整七子规则：50 普通役 + 20 高役，七对特殊形、九莲、大七星
- 四档 AI：简单 / 普通 / 困难 / 修罗（MCTS）
- 新手引导、规则速查、战绩统计、成就与牌谱回看
- 本机单机运行，无需联网；支持 F11 全屏与大字号界面
- 无内购、无抽卡、无真实货币赌博

Mahjong、Card Game、Singleplayer、Strategy、Turn-Based、Relaxing、Anime（可选）

## English

**Short description**

A single-player mahjong variant with 7-fu minimum wins, call-lock, misfire penalties, table bonuses, and four AI tiers.

**Long description**

Tiisu Mahjong is a single-player desktop implementation of the Tiisu ruleset: 136 tiles, 7-fu minimum, call-lock, misfire penalties, table bonus pool, and four AI tiers.

- Full Tiisu rules: 50 normal yaku + 20 high yaku, special seven-pairs shapes, nine gates, Great Seven Stars
- Four AI tiers: Easy / Normal / Hard / Shura (MCTS)
- Tutorial, rules reference, match stats, achievements, and replay viewer
- Fully offline single-player; F11 fullscreen and large-text UI
- No microtransactions, loot boxes, or real-money gambling
