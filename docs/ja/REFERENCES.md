# 技術参考

開発中に行った外部技術調査と、**使用していない**内容を記録し、出典の問い合わせに答えられるようにする。

## Alice in Cradle

- 調査範囲：空間オーディオの設計思想（Unity 内ミドルウェア）。
- 未使用：当該ゲームのコード、Unity ミドルウェア、素材、派生物は取り込んでいない。
- 本作のオーディオ経路は独自実装で、当該ミドルウェアへの依存はない。

## 明星三缺一 2002

- 調査範囲：FFmpeg による参考音の包絡・長さ・密度の一般的な特徴分析。
- 未使用：原音声の埋め込み、サンプリング、転写、再配布はなし。原作コード・美術も未使用。
- 本作の効果音は `tools/Tiisu.AudioGen` で独自合成しており、聴感は参考音と異なる。

## 読み上げ音声

- 音声はインストーラーに含めない。実行時に Windows SAPI で `%LOCALAPPDATA%\TiisuMahjong\voices` に生成する。
- 第三者の録音は使用・埋め込みしない。出力はローカル Windows ライセンスに従う。

## フォント
