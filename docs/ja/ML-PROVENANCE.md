## 学習データ

- エンジン自己対戦 + 10% のランダム合法打牌探索のみ。
- MCR / Tenhou などの外部データセットは不使用。旧 v2 重みは削除済み。
- 特徴量 339 次元：牌山を除く場況 + 手牌構造（三色同順／同刻、五門斉、対々など）。
- 報酬：終局点差 + 鳴き／向聴／誤宣言／放銃／降り／リード減衰を `tanh(raw/20)` で正規化。
- 特徴量の z-score 正規化は重みと一緒に保存。
