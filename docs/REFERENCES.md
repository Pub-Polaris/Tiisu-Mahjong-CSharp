# 技术参考说明

本文记录开发阶段做过的外部技术研究，以及明确**没有使用**的内容，便于回答来源问题。

## 《Alice in Cradle》

- 研究范围：空间音频的架构思路（Unity 内中间件）。
- 未使用：没有引入该游戏的代码、Unity 中间件、资源文件或衍生产物。
- 本项目音频链路为独立实现，与该中间件无依赖关系。

## 《明星三缺一 2002》

- 研究范围：用 FFmpeg 对参考音做包络/时长/密度层面的通用特征分析。
- 未使用：没有嵌入、采样、转录或分发原作音频；没有复制原作代码或美术资源。
- 本项目音效由 `tools/Tiisu.AudioGen` 独立合成，实际听感与参考音不同。

## 原则

- 只借鉴**不受著作权保护的功能性特征**（规则、时长、密度、包络走势）。
- 不复制受保护的表达（代码、音频、美术、UI、角色、logo）。
- 项目与原作作者无关联，也未获得其背书。
- 商品名与商标归各自权利人所有；本项目名称与宣传不使用上述游戏名称。

> 本文是技术来源说明，不构成法律意见。正式发行前建议按目标地区与 EULA 复核。
