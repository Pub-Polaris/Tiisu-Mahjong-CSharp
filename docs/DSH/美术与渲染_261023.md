# 美术 / 渲染方向（261023 确认）

## 结论

| 项 | 决定 |
|---|---|
| 美术流程 | **A：保持 Skia 手绘 + 资产流水线**（PNG/SVG 资产 + `TableLayoutSpec` 数值 + `--render-*` 出图评审） |
| 渲染后端 | **上 GPU**：`SKControl` → `SKGLControl`，用 `GRContext` 绘制 |
| 布局编辑器 | **做**：应用内可拖拽摆位、保存 JSON 的编辑模式 |

## GPU 改造要点

- `ScreenHost` 宿主控件换成 `SKGLControl`（SkiaSharp.Views.WindowsForms），`PaintSurface` 里用 `e.Context` 的 `GRContext`
- 无 GPU / 驱动异常时**自动回退 CPU**（`SKControl`），不能白屏或崩
- `--render-*` 无窗口命令保持 CPU 光栅（离屏 surface），不受影响
- 验收：`--bench 600` 改造前后对比（当前 CPU：4.17 ms/帧 ≈ 240 fps）；安装包在无显卡环境仍可启动

## 布局编辑器要点

- 编辑模式入口：菜单/快捷键（如 F2），牌桌上叠加显示 `TableLayoutSpec` 各区域矩形 + 名称
- 鼠标拖拽移动区域、滚轮/Shift 调整尺寸、方向键微调
- 保存到 `%APPDATA%\TiisuMahjong\layout-custom.json`，启动时若存在则覆盖默认 spec
- 重置回默认值
- 验收：拖完保存 → 重启仍生效 → 一键重置；截图对比
