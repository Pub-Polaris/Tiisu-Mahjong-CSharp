# 桌面伪 3D 透视参考（SKMatrix44）

来源：北极星提供（`deepseek_csharp_20261023_0a3826.cs`）。

```csharp
// 1. 4x4 透视矩阵：FOV 55°、宽高比、近/远裁剪
var perspective = SKMatrix44.CreatePerspective(55f, 1.33f, 1f, 100f);

// 2. 绕 X 轴后倾 55°（把桌面“放平”）
var rotateX = SKMatrix44.CreateRotationDegrees(1, 0, 0, 55);

// 3. 组合并应用到画布
perspective.PostConcat(rotateX);
canvas.Concat(ref perspective);

// 4. 在倾斜坐标系里画桌面（牌桌矩形、遮罩）
// canvas.DrawRect(...)

// 5. 恢复坐标系，再画立在桌面上的牌（不受桌面倾斜影响）
canvas.Restore();
```

## 接入要点（给 2.5D 渲染层）

- 桌面层：`canvas.Save()` → Concat 透视矩阵 → 画牌桌底板/纹理/暗角 → `Restore()`
- 牌层：**不套桌面矩阵**；牌身用「正面 + 侧面厚度 + 投影」模拟立起，位置仍按逻辑坐标
- 命中测试保持逻辑坐标不变（输入换算不参与透视）
- 变体参数：轻度/中等 = 改变 `rotateX`（如 25° / 45°）、牌厚与投影半径
