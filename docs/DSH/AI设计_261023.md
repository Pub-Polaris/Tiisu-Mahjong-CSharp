# AI 设计（261023 · 北极星确认）

## 目标与约束

- 用途：陪玩为主，**随机分配难度**给三个 AI，也允许房主按座位锁定/调比例
- **信息公平**：所有档位都**不读别家手牌、不读牌山**，只看副露、暗杠、牌河
- 确定性：同 seed 同决策（随机源注入）
- 思考时间：**自适应**——普通局面快出，关键/纠结局面加深

## 四档难度

| 档 | 核心 | 思考 |
|---|---|---|
| 简单 | 惯性 + 噪声，不防守 | 毫秒 |
| 普通 | 向听 + 进张（ukeire） | 毫秒 |
| 困难 | 打点期望 + 放铳风险 + 副露判断 | 毫秒～几十毫秒 |
| 修罗 | **MCTS（实验性）**，默认关闭 | 自适应预算（关键局面 ≈300 次模拟，普通 ≈100） |

难度分配默认权重：**简单 30% / 普通 45% / 困难 20% / 修罗 5%**；房主可改比例或锁定单座。

## 真人模拟（失误）

- 可控失误率，按档位设定基线，**紧张度越高上浮 1–3 个百分点**
- 失误类型：漏听、打错牌（次优解）、该防守时不防守
- 修罗档不注入失误

## 自适应思考触发（两者结合）

1. **评分差距**：top1 与 top2 分差过小（如 <5%）→ 加深
2. **局面关键点**：进听、听牌、危险牌、被鸣牌后 → 加深
3. 深度上限按难度与 MCTS 预算

## 视觉/结算口径（本轮确认）

- **暗杠展示**：牌背先只翻 2 张（第 2、4 张），和牌后把其余牌翻开，并盖 **30% 黑色遮罩**表示“和牌后翻开”
- **供托改名「场赏」**：数值 = **700 × 连庄数**，和牌者取走；与现有连庄奖励同额（不重复加）
- 连庄计数沿用现有 `Honba`（本场）

## 实现分期

| 期 | 内容 |
|---|---|
| A | `Shanten`（标准形/七对/国士）+ `Ukeire` + 分档弃牌评分 + 难度分配 + 失误/紧张度 + 确定性；**旧 `AiPlayer.ChooseDiscardIndex` 保留**（ai-golden 4796 条必须继续 0 差异） |
| B | `ThreatModel`（现物/筋/壁 + 副露威胁 + 场况）与防守权重 |

| D | 暗杠展示 / 场赏 UI（App 侧） |
