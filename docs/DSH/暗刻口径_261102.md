# 暗刻口径（2026-11-02）

规则由北极星确认，替换此前「手牌里同种牌 ≥3 就算暗刻」的实现。

## 1. 暗刻必须自成一个面子

- 判定暗刻只看**暗手拆出来的刻子**（拆牌结果里的 `Pung`），不再按张数直接数。
- 例：`123m + 33m`（合计 `1m2m3m3m3m`）——3m 有三张，但拆牌是「123 顺子 + 33 雀头」，
  **不存在 333 刻子**，所以不能算暗刻。
- 暗杠照旧计入（`_ankanCount`）。

## 2. 荣和凑出来的刻子不算暗刻

- 荣和时，用来点炮的那张牌若参与某个刻子，该刻子**不算暗刻**。
- 只有**自摸**凑成的刻子才算暗刻。
- 例：`22m` 手牌 + 荣和 `2m` → `222m` 是明刻；同手牌自摸则算暗刻。

## 实现

- `WinChecker.CheckOne` 记录暗手拆牌结果 `_concealedGroups`（不含副露）。
- `WinChecker.Conditions.ConcealedAnkouCount()`：
  - 遍历 `_concealedGroups` 里的 `Pung`；
  - `!_selfDraw && group.Tiles[0] == _winTile` 时跳过；
  - 加上 `_ankanCount`。
- 无拆牌信息（七对等）时退回按张数兜底，但同样排除荣和的那一张。

## 影响

- 两暗刻 / 三暗刻 / 四暗刻的成立条件变严：yaku-golden 968 条期望值变化（三暗刻 → 两暗刻等）。
- 四暗刻（役满）同样受限：荣和点炮凑出的第四刻不再算四暗刻。
- AI 评估受打点变化影响：ai-golden 1 条决策变化。
