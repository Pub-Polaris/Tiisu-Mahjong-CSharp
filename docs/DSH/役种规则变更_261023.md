## 3. 杠子役细则

- 带**明杠**时，杠子役赋 **-1**：两杠子 3→2，三杠子 5→4
- 杠子役**吃掉根役**：两杠子/三杠子/四杠系成立时，不再计「一暗杠 2」「明根 1」

## 4. 四子七对（新增硬编码特殊役）

- 条件：**七对结构**（14 张全成对），且**恰好一种牌是四张同牌**
- 若出现**两种及以上**四张同牌 → 七对不成立
- 结算：**固定 7000 点**，与「七对子」**互斥**，**可叠其他役**
- id 建议 `four_pairs_seven`，显示名「四子七对」
