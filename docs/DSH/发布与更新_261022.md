# 发布与替换式更新（261022）

## 安装

```
powershell -ExecutionPolicy Bypass -File NET\installer\build_installer.ps1
```

产物：`NET\dist\TiisuMahjong-Setup.exe`（当前 ~14 MB）

- 框架依赖（机器需 .NET 10 Desktop Runtime，安装器会检测并给下载页）
- 装到 `%LOCALAPPDATA%\Programs\TiisuMahjong`，**不写注册表**
- 发布前自动剔除 `*.pdb`（安装目录 159 MB → 45 MB）
- 包内包含：主程序 + `Assets\`（牌面雪碧图 / 菜单布局）+ `Tiisu.Updater.exe` + `version.json`

## 存档

用户数据在 `%APPDATA%\TiisuMahjong\`：`settings.json` / `state.json` / `stats.json` / `logs\`。
**更新与卸载都不碰它**。

## 替换式更新（不卸载、不重装）

```
Tiisu.Updater.exe --apply "D:\下载\Tiisu-v2.zip" --restart
Tiisu.Updater.exe --apply "E:\build\publish"          # 目录也行
Tiisu.Updater.exe --apply "..." --install "安装目录"   # 默认识别自身所在目录
```

行为：

1. 等 `Tiisu.Mahjong` 退出（最多 60 秒）
2. 整个安装目录备份到 `backup\update_<时间戳>`
3. 新文件覆盖（Updater 自身文件跳过；其余文件锁冲突最多重试 30 秒）
4. 合并写 `version.json`：保留新包的 `version` / `buildTime`，补 `updatedAt` / `source`
5. `--restart` 时重新拉起主程序

手工替换也行：把新构建解压覆盖安装目录即可，效果相同。
