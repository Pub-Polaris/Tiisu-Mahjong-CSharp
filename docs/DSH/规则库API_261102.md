# 规则库 API 契约（Tiisu.Core + Tiisu.Engine）

> 2026-11-02 第一版。目的：让「别的外壳」（Unity / Godot / Web / 机器人 / 命令行）能只引用
> `Tiisu.Core.dll` + `Tiisu.Engine.dll` 就完整跑七子麻将的判役与对局，不需要 WinForms / Skia。
>
> 本文件描述的是**对外承诺**；未列出的类型/成员视为内部实现，可能随时改名或删除。

## 1. 产物与版本

| 项 | 值 |
|---|---|
| 程序集 | `Tiisu.Core.dll`（判役/牌型/数据）、`Tiisu.Engine.dll`（流程/结算/AI/自走） |
| 目标框架 | `net10.0`（无平台依赖；WinForms/Skia 只在 `Tiisu.App` 里） |
| 依赖 | Core 仅 `System.Text.Json`；Engine 仅引用 Core |
| 版本号 | 与主程序同一个构建号：`yymmdd-<git short hash>`（程序集版本同步写入） |
| 分发 | `dist/lib/` 目录（dll + pdb + xml 文档）与 `Tiisu.Rules.<版本>.zip`，由 `tools/build_rules_lib.ps1` 生成 |

**兼容性承诺**：同一 `yymmdd-hash` 内保证二进制兼容；跨构建号不承诺 ABI（规则本来就会改）。
升级方式：整包替换 dll，重新编译宿主。

## 2. 最小上手：判一手牌

```csharp
using Tiisu.Core;

var checker = new WinChecker(YakuData.LoadDefault());
var result = checker.CheckWin(
    hand: new[] { Tile.Parse("1m"), Tile.Parse("2m"), Tile.Parse("3m"), /* … 共 14 张 */ },
    selfDraw: false,
    hasCalled: false,
    ankanCount: 0,
    minkanCount: 0,
    melds: Array.Empty<Meld>(),
    firstTurn: false,
    winTile: Tile.Parse("3m"),
    context: null);

if (result.Success)
{
    Console.WriteLine($"和牌 {result.TotalFu} 赋");
    foreach (var y in result.ActiveYaku)
    {
        Console.WriteLine($"  {y.Name} {y.Fu} 赋");
    }
}
```

要点：
- `hand` 是**含和牌张**的 14 张（有副露时 = 14 − 副露张数 + 杠数）。
- `winTile` 传和牌张，**荣和时暗刻判定依赖它**（点炮凑成的刻子不算暗刻）。
- `context` 传场况（自摸/海底/岭上/门风等），不传则按门前普通和牌判定。

## 3. 最小上手：跑一整场（自走）

```csharp
using Tiisu.Engine.SelfPlay;

var result = SelfPlayDriver.Run(seed: 20261102, modeTarget: 4);
Console.WriteLine($"局数={result.Rounds} 最终点数={string.Join(",", result.FinalScores)}");
Console.WriteLine($"事件流 SHA256={result.EventHash}");
```

同 seed → 同事件流（洗牌、骰子、AI 决策全部走同一个 `IRandomSource`）。

## 4. 引擎驱动（自己做 UI 时）

```csharp
using Tiisu.Engine;
using Tiisu.Engine.Deal;
using Tiisu.Engine.Random;

var engine = new MahjongEngine(randomSource: new Mulberry32Random(seed: 1));
engine.SetMode(4);                       // 东风场

var layout = RoundDealFactory.Cut(dealerIndex: 0, random: new Mulberry32Random(1));
engine.SetDiceInfo(null, layout.Dice, layout.SkipTiles);
engine.StartNewRound(layout.Deal);       // 配牌完成，轮到庄家

var dealer = engine.Players[engine.TurnIndex];
engine.DrawFromWall(dealer);             // 摸牌
engine.Discard(dealer, dealer.Hand[0]);  // 出牌
engine.CheckSpecialFlow();               // 四风连打等
engine.NextTurn();                       // 交棒
```

宿主职责：
- 摸牌 / 出牌 / 副露 / 和牌**由宿主调用**引擎方法（引擎不自己跑循环，`SelfPlayDriver` 才是全自动）；
- 和牌：先 `engine.Checker.CheckWin(...)` 判定，再 `engine.DeclareWin(winIndex, selfDraw, settlement, discarderIndex)`；
- 流局：`engine.Flow()`；特殊流局：`engine.DeclareSpecialFlow(reason)`；
- 下一局：`engine.AdvanceRound()` 返回是否继续，然后用新的 `RoundDealFactory.Cut(...)` 开下一局；
- 计时、动画、存档、网络全部是宿主的事。

## 5. 对外类型（承诺范围）

### 5.1 Core（全部 13 个都属于承诺范围）

| 类型 | 用途 |
|---|---|
| `Tile` / `Suit` | 牌（`Tile.Parse("5z")`、`Index`、`IsHonor`、`IsTerminal`） |
| `TileCounts` | 36 格计数表（判役常用） |
| `Meld` / `MeldType`* | 副露（吃/碰/明杠/暗杠/加杠） |
| `Group` / `GroupKind` | 拆牌结果（雀头/顺子/刻子） |
| `HandKind` | 手牌类型（标准形/七对/国士） |
| `WinChecker` | 判役入口 `CheckWin(...)`，`MaxSplit` 控制是否枚举全部拆法 |
| `WinResult` / `YakuResult` | 结果（`Success`、`TotalFu`、`ActiveYaku`、`SpecialPoints`、`SevenHonors`） |
| `WinContext` | 场况（海底/岭上/门风/河牌可见数等） |
| `YakuData` / `YakuDefinition` / `TokureiDefinition` | 役种数据与特例（一般只需 `YakuData.LoadDefault()`） |

\* `MeldType` 定义在 Engine（`Tiisu.Engine`），Core 的 `Meld` 用字符串 type 保持与 Web 语料一致。

### 5.2 Engine（承诺范围）

| 类型 | 用途 |
|---|---|
| `MahjongEngine` | 对局状态机：`StartNewRound` / `Draw` / `DrawFromWall` / `Discard` / `NextTurn` / `ApplyMeld` / `DoKan` / `Flow` / `DeclareWin` / `DeclareMultiRon` / `AdvanceRound` / `CalcPoints` / `CalcFinalPoints` / `IsTenpai` |
| `Player` | 手牌、副露、河、报听状态（`IsCalled` / `CalledWaitMask`） |
| `EngineState` / `SeatWind` / `MeldType` | 枚举 |
| `RoundDeal` / `RoundDealFactory` | 开局：配牌 + 切牌 + 骰子 |
| `PointsConfig` | 赋位表（默认从内嵌 `ike.json` 读） |
| `WinSettlement` / `WinYaku` | 结算输入/输出（结算屏数据源） |
| `IRandomSource` / `Mulberry32Random` | 可注入随机源（复现用） |
| `SelfPlayDriver` / `SelfPlayOptions` / `SelfPlayResult` | 整场自走与结果 |
| `TieredAi` / `AiLevel` / `AiTuning` | AI 出牌入口（Simple / Normal / Hard / Shura） |
| `TenpaiCalculator` / `TenpaiEntry` / `TenpaiOptions` | 听牌列举（牌形口径见 `Formed`） |
| `Shanten` / `ShantenKind` | 向听计算 |

### 5.3 明确不承诺（内部实现）

- 回放：`ReplayDriver`、`ReplayCorpus`、`Replay*`、`StateDiff`、`EngineWire`
- AI 内部：`AiPlayer`、`AiPlayerObservation`、`AiPlayerView`、`AiCandidate`、`AiMeldOptions`、`MistakeModel`、`MctsAi`、`ThreatModel`、`Ukeire*`
- 构造细节：`DealLayout`、`WallLayout`、`TileSetFactory`、`ChiOption`、`RonCandidate`、`CallPenalty`
- 变更办法：这些暂时仍是 `public`（为了测试与工具），但随时可能改签名或改 `internal`；外部不要依赖。

## 6. 关键语义（容易踩）

| 规则 | 说明 |
|---|---|
| 起和线 | 7 赋；赋 < 7 不能和（`Reason = "no_yaku"`，`TotalFu` 仍会给出） |
| 庄家 ×1.5 | `CalcFinalPoints` 给子家点数；庄家再乘 1.5，再加 `HonbaBonus()` |
| 荣和 | **全铳制**：放铳者付全额，其他两家分数不变 |
| 暗刻 | 只认拆牌结果里的刻子，且荣和点炮凑成的刻子不算（见 `docs/DSH/暗刻口径_261102.md`） |
| 报听 | `CanDeclareCall` / `DeclareCallWithHand`；锁手用 `CallAllowsDiscard` |
| 赐马 | `ResolveMa(winner, settlement)`，表外按 700 点/个 |
| 流局罚 | `Flow()` 内部执行；`LastFlowPenalties` 给出人读文案 |
