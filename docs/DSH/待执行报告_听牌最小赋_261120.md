## 无效 JSON 溯源

时间：2026-11-20 17:29 左右

错误：

```text
DeepSeek Messages stream: tool input is invalid JSON
MALFORMED_RESPONSE
```

会话原文：

```text
session-92ac2302-0d4f-41bb-bcf1-46cfa43bddf0
turn 536, step 19
tool: exit_plan_mode
```

已确认：

- 这是**本次会话主 agent 自己**生成的 tool call
- 不是用户、不是子 agent、不是仓库 JSON 文件
- 流式 tool arguments 在 `### 2. TenpaiCalculator` 附近结束，缺少结尾引号和 `}`
- 拼起来的 arguments 不是合法 JSON，DSH 报 `MALFORMED_RESPONSE`
- 属于模型输出被截断，不是 DSH 把合法 JSON 改坏
- 同轮还有一次相同错误；之后重新生成才恢复

结论：**主 agent 的长 `exit_plan_mode` 参数被截断，导致 invalid JSON。**

规避：长计划先落文件，再让工具只引用文件；不要把所有内容塞进一个超长 tool argument。
