# 布局编辑器设计（方案 C · 261023）

目标：应用内拖拽调整牌桌布局，存 JSON，可重置。美术调整不再依赖改代码数值。

## 交互

| 操作 | 行为 |
|---|---|
| `F2` | 进入/退出编辑模式 |
| 左键拖拽区域 | 移动该矩形 |
| 滚轮 | 缩放矩形（以左上角为锚） |
| Shift + 滚轮 | 只改高度 |
| 方向键 | 1px 微调（Shift 10px） |
| `S` | 保存到 `%APPDATA%\TiisuMahjong\layout-custom.json` |
| `R` | 恢复默认（删除自定义文件，需二次确认） |
| `Tab` | 循环选中下一区域 |

## 覆盖范围

- 牌桌（`TableLayoutSpec` 全部命名区域）：手牌、副露、牌河、牌山、HUD、按钮条、结算面板、缩略图
- 菜单与设置屏（`Assets/layout/*.json`）后续接同一套

## 存储

```json
{
  "version": 1,
  "regions": { "hand": {"x":360,"y":980,"w":480,"h":120}, "...": {} }
}
```

启动时若存在则覆盖 `TableLayoutSpec` 默认值；解析失败 → 忽略并写日志。

## 实现要点

- 新增 `Table/LayoutEditor.cs`：持有选中项、拖拽状态、脏标记
- `TableLayoutSpec` 的区域列表要可枚举（名称 + Rect），当前若散落在字段里，抽成字典
- 编辑层在 `TableScreen.Draw` 之后叠加绘制：半透明填充 + 名称 + 坐标
- 保存/加载放 `Runtime/CustomLayoutStore.cs`，与 `Settings` 同目录

## 验收

1. `F2` 进入、拖拽、保存、重启后生效
2. `R` 恢复默认
3. 截图：编辑态显示区域框与坐标
4. 布局文件损坏时程序正常启动
