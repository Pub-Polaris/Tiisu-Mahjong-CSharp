# 报听机制（叫胡）· 规则与实现口径（261023）

> 北极星定义的**新规则机制**（规则书里没有；立直/双立直仍保持移除）。

## 1. 宣言条件

- 手牌处于**听牌状态**即可报听
- **不限门清/副露**（有碰吃杠也可以报听）
- 时机：本次操作（弃牌 / 过牌 / 副露 / 杠）**执行之后**，手牌为听牌状态时即可宣言

## 2. 报听后

- **锁手**：此后所有操作（摸切、弃牌、副露、杠）都不得改变听牌形
- 唯一例外：**不破坏听牌形的暗杠**可以
- **玩家手动操作**（不自动摸切）
- 正常和牌 → 正常结算，解除报听
- 报听本身**不给赋、无收益**

## 3. 错和（误报和牌）

定义：报听后宣布和牌，但该手实际**赋 < 7（未达起和线）**。
**只有这一种情况算错和。**

### 3.1 普通错和（Z ≤ 2100 点）

- `Z = 该手赋数 × 700`（不含赐马）
- 违规家向**其他三家各支付 Z**
- 本巡禁止和牌；本次和牌不成立；**解除报听**
- 本巡结束前**不可改手**

### 3.2 重罚错和（Z > 2100 点，即赋 ≥ 4）

- 违规家向三家支付：**子家违规 → 庄家 14000、其余两家各 7000**
- **本局禁止和牌 + 下局禁止和牌**
- 本次和牌不成立；解除报听；**不可改手**

## 4. 流局

- 流局时四家手牌**全部翻开**（和牌者、未和牌者都翻）
- **未听牌家**的手牌加黑遮罩
- 该遮罩效果统一叫 **【灰显】**（30% 黑）

### 4.1 261024 口径修正：保留两个罚项，无役 =「一个役都数不出来」

北极星实测发现「鸣牌后无役听牌罚」误判（手牌明明有断幺九却被判无役）。错的不是罚项本身，
是判定口径：原来拿 `listTenpai` 的 `success`（= 赋数够 7 起和线）当「有役」，于是赋 &lt; 7 的手全被当成无役。

261024 最终口径：

- **保留两个罚项**：`ApplyNotenKanPenalty`（未听返杠 700/杠）、`ApplyNoYakuTenpaiPenalty`（鸣牌后无役听牌：子家 −1400 / 庄家 −2100）
- **「无役」= 一个役都数不出来**：对每张听牌张调一次 `WinChecker`，役列表里存在 `Fu > 0 && !IsBonus` 的项就算「有役」
  - **不设赋数门槛**：「赋 &lt; 7 不能和」≠ 无役。断幺九 2 赋、碰白/发/中、门风/圈风役牌哪怕只有 1 赋，都算有役 → 不罚
  - **表外赋不算役**：听牌型奖赏（嵌张 / 边张 / 单钓 / 双碰 / 筋和）、赐马
  - 判「数得出役」用**荣和口径**：自摸 2 赋 / 卡七自摸加成这类「靠自摸才加的赋」不算役（见 §10）
- 只在「有副露 + 有听牌形 + 全部听牌张都无役」时罚；**门清不罚**（罚项只针对鸣牌后）
- 流局其它逻辑不变：翻牌 `RevealHands = true`、连庄/本场 +1、三家听牌本场 +1、七日终战过庄
- 「拔厄」不属于荒牌流局，保持原样
- 错和只在**玩家主动点「和牌」误报**时产生，流局永不产生错和分

## 6. 已确认的交互（261023 补充）

### 6.1 报听后的荣和

- **可以荣和**，也可以选择**跳过**（等自摸），照常出荣和窗口/「过」按钮
- 荣和成功后按正常结算并解除报听

### 6.2 错和 + 多家和牌

- 错和家**照罚**（按第 3 节）
- 依然按**双和子**结算并跳庄，但**错和家不算**
- 错和家若是庄家：正常结算错和罚点，同时顺带结算其他真和牌家的点数
- **只要出现真实和牌，本局即结束**；庄家本身错和未和牌 → 依然**过庄**

## 8. 遗留项已确认（261023 二轮）

| 项 | 结论 |
|---|---|
| 报听可用时机 | 自家弃牌时 **+ 副露窗口（吃/碰/杠/荣和窗口）** |
| 锁手强度 | **听牌张不能变**（严格） |
| 杠的例外 | 仅「听牌形不变」的**暗杠**允许；加杠/明杠禁止 |
| 吃碰 | **禁止** |
| 按钮 | 同一个「听牌」按钮改为**报听按钮**：真听牌才可用；待牌提示常显 |
| 状态字段 | `isCalled`（报听=叫胡） |
| 人和 | 互不影响；人和本身 = 子家在各家未副露前听牌并和牌 |
| 首巡听牌 | 不受报听影响（看第一巡结束是否听牌） |
| 流局申报 | 已报听者**自动算听牌**，不用再申报 |
| 二次确认 | **无**，点击即报听 |
| 取消报听 | **不可主动取消**；仅在和牌 / 错和 / 流局时解除 |
| 日志/回放事件名 | `call` |

## 10. 实现细则（lead 已拍板，代理按此执行）

| 项 | 结论 |
|---|---|
| 自摸赋是否算役 | **不算**（判「数得出役」用**荣和口径**：排除自摸 2 赋 / 门前自摸 4 赋；其余役含 1 赋役牌都算） |
| 罚项必须能触发 | 是——必须存在「一个役都数不出」的手（只有表外赋/宝牌不构成役） |
| 庄家错和重罚 | 三家**各付 7000**（合计 21000） |
| 子家错和重罚 | 庄家 14000、另两家各 7000（合计 28000） |
| 错和触发方式 | 自摸、**荣和**都可以（点了「和牌/荣和」按钮即算）；同张牌上其他家真和牌照常结算，庄家未和则过庄 |
| 自家出牌时报听交互 | 亮按钮 → 点「报听」进入待弃 → 再点一张手牌打出（无二次确认） |
| 副露窗口报听 | 手牌已是 13 张听牌形 → 点「报听」立即生效 |
| 「本巡禁和」定义 | 到该家**下一次轮到自己**为止，不影响他家 |
| 无役听牌罚（流局） | **保留**：有副露 + 听牌形 + 所有听牌张都数不出役 → 子家 −1400 / 庄家 −2100 |
| 未听返杠 | **保留**（700/杠） |
