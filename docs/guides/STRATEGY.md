# 七子麻将 · 打牌指南

## 一、先记住七子的不同

- 起和线默认 **7 赋**，不是随便有役就能和。
- 副露会同时影响：役种、赋数、门前自摸、防守信息。
- 可选役默认关闭；不要按“全可选役”的统计判断普通对局。
- 七子有报听、马牌、赏、双和等独有规则，先看设置里的当前规则。

## 二、开局先定方向

### 1. 看起手结构

- **对子多**：七对子，保留对子，不要随意拆。
- **同一花色多**：混一色/清一色，尽量少副露。
- **字牌多**：字一色/大七星方向，但不要为了一个字牌拆掉正常和牌。
- **幺九多**：清老头、混老头、纯全/混全带幺。
- **搭子整齐**：优先正常牌效，不强行追大牌。

### 2. 不要只看“最大役”

先判断：

1. 现在离听牌多远？
2. 正常和牌能不能过起和线？
3. 追大牌会不会把和牌率打到不可接受？

七子里，**过不了起和线的听牌没有意义**。

## 三、副露

- 副露不是越多越好；它会降低门清价值，也会暴露牌型。
- 字一色允许副露；大七星、九莲、四暗杠、七对需要门清。
- 清一色、混一色可以副露，但要看追役权重和当前和牌速度。
- 副露后如果和牌赋数过不了起和线，不如不副露。

## 四、防守

- 先看对手牌河和副露，不要只看自己手牌。
- 中后盘、自己离听牌远时，优先切现物和低危险牌。
- 不要为了保留一张进张，把明显危险的牌打出去。
- 追大牌时，放铳成本要算进去；追役不是无风险。

## 五、7Neuu 自动追役

7Neuu 在满足条件时会自动判断是否追特殊役：

- 早期/中期、未和牌、非关键局才进入
- 目标可能是七对、字一色、混/清一色、大七星、九莲、四暗杠
- 追役状态会使用随机采样（temperature），普通状态仍是 argmax
- 追役时减少副露；字一色是例外
- 牌山不足、目标不再可行、进度变差时退出

玩家可调五项：

| 权重 | 作用 |
|---|---|
| 进攻 | 保留目标牌的倾向 |
| 防守 | 追役时对危险牌的惩罚 |
| 副露 | 追役时允许副露的倾向 |
| 打点 | 目标价值偏好 |
| 追役 | 进入追役的积极性和采样 T 参数 |

### 三个预设

- **稳守**：少追役、多防守
- **均衡**：接近默认
- **追役**：更愿意为特殊役保留牌

## 六、练习顺序

1. 先练正常牌效：向听、进张、听牌
2. 再练起和线：知道自己差几赋
3. 再练副露选择：副露后还能不能过线
4. 最后练守备和追役
5. 特殊役用挑战模式练，不要拿普通对局强行追

## 七、常见错误

- 只看手牌，不看对手副露
- 为了一个役拆掉已经成型的顺子
- 追清一色却不看自己已经副露
- 副露后才发现赋数不够
- 把“可选役全开”的频率当成默认
- 用单局结果判断 AI 强弱；至少要看几十局

## 八、关于图片

游戏内 Markdown 页目前以文字和表格为主，牌例用 `123m`、`456p`、`77z` 这种牌谱写法。  
以后要加图，只使用项目自己的 `tiles.png` 牌面或自绘 SVG，不从网络抓图。
