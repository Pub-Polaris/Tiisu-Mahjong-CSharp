# 七子麻将 · 役种表

> 这是游戏内速查，不是规则书全文。  
> 牌例写法：`123m` = 一万二万三万，`456p` = 四筒五筒六筒，`77z` = 双中。  
> “赋”是七子的点数单位；起和线默认 7 赋，具体以对局设置为准。

## 牌型写法速查

- 数字串后跟花色；花色作用于前面整段数字
- `_` 表示额外空 2px
- 吃 / 碰 / 暗杠 / 明杠：`c` / `b` / `a` / `k`

- 字牌：`123z456z`
- 七对：`11223344556677z`
- 空位：`11m_22m_33m`
- 吃 / 碰：`c123m` `b777z`
- 暗杠 / 明杠：`a222z` `k333p`

## 一、先了解赋和起和线

- 普通和牌不是“有役就能和”，还要达到**起和线**。
- 起和线默认 **7 赋**；可选役关闭时按默认役种表计算。
- 门清、副露、自摸、荣和会影响可成立的役和赋数。
- 同一手牌可能同时成立多个役；判役器会按上下位关系处理重复。

## 四、容易记错的点

- **字一色不要求门清**，可以副露。
- **大七星**是七对结构，七对天然门清。
- **九莲宝灯**要求门清。
- **四暗杠**天然由暗杠组成。
- 选到可选役时，显示和统计会变化；默认统计不要和“全可选役”混在一起。
- 以游戏内判役器的实际结果显示为准；本表用于方向性速查。
