## 训练数据

- 仅引擎自走 + 10% 随机合法弃牌探索。
- 不使用 MCR / Tenhou 等外部数据集；旧 v2 权重已移除。
- 特征 339 维：除牌山外全部场况 + 牌型结构（三色同顺/同刻、五门齐、对对等）。
- 奖励：终局点数差 + 吃碰/向听/错和/放铳/弃和/领先衰减，`tanh(raw/20)` 归一化。
- 特征 z-score 归一化随权重保存。
